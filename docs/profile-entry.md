# Suggested profile project entry

## BreastMRI-Workbench

[Repository](https://github.com/a978623/BreastMRI-Workbench)

A napari plugin for breast DCE-MRI exploration: NIfTI loading, static 3D ROI
painting, signal/enhancement curves, explicit data quality checks, and portable
analysis reports. Includes a deterministic synthetic demo and automated tests.

![Synthetic demo](https://raw.githubusercontent.com/a978623/BreastMRI-Workbench/main/docs/images/workbench.png)
